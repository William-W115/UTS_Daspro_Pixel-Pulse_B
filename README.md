# Program Parkir Mall Sederhana
Program Parkir Mall Sederhana adalah program berbasis bahasa Pascal yang digunakan untuk mengelola parkir mall secara sederhana. Program ini memungkinkan pengguna mencatat kendaraan masuk dan keluar, menghitung biaya parkir, menampilkan status tempat parkir, serta mencatat total pendapatan parkir.

# Fitur-Fitur Utama dan Logika Singkat
Program Parkir Mall Sederhana memiliki beberapa fitur utama untuk membantu pengelolaan parkir mall.  
1. Fitur kendaraan masuk memungkinkan pengguna memilih jenis kendaraan, yaitu mobil atau motor. Program memeriksa ketersediaan slot parkir sebelum menambah jumlah kendaraan. Setiap jenis kendaraan memiliki kapasitas maksimal 10 kendaraan.   
2. Fitur kendaraan keluar memungkinkan pengguna memilih jenis kendaraan dan memasukkan lama parkir dalam jam. Program memeriksa apakah kendaraan tersedia di parkiran. Jika tersedia, program menghitung biaya parkir sesuai jenis kendaraan dan lama parkir, kemudian mengurangi jumlah kendaraan yang terparkir.  
3. Fitur perhitungan biaya parkir digunakan untuk menentukan tarif berdasarkan jenis kendaraan dan lama parkir. Tarif mobil adalah Rp5.000 untuk jam pertama dan Rp3.000 untuk setiap jam berikutnya, sedangkan tarif motor adalah Rp2.000 untuk jam pertama dan Rp1.000 untuk setiap jam berikutnya. Biaya tersebut kemudian ditambahkan ke total pendapatan parkir.  
4. Fitur status parkir menampilkan kondisi tempat parkir mobil dan motor menggunakan simbol [X] untuk slot terisi dan [ ] untuk slot kosong. Program juga menampilkan jumlah kendaraan, slot yang tersedia, serta total pendapatan yang diperoleh.  
5. Fitur validasi input memastikan bahwa pengguna memasukkan bilangan bulat, memilih jenis kendaraan yang benar, dan memasukkan lama parkir minimal satu jam. Validasi ini membantu mencegah kesalahan input saat program dijalankan.  
6. Fitur menu utama dan keluar program memungkinkan pengguna memilih tindakan yang ingin dilakukan, seperti kendaraan masuk, kendaraan keluar, atau melihat status parkir. Menu ditampilkan berulang kali menggunakan perulangan repeat-until sampai pengguna memilih menu 0 untuk mengakhiri program.
